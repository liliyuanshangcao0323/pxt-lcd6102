# 学校网页学生会管理系统

## 项目简介

这是一个基于Web的学生会管理系统，旨在帮助学校学生会高效管理日常事务、活动组织、成员信息以及与学生群体的沟通。系统采用模块化设计，具有良好的可扩展性和维护性。

## 功能特点

### 核心功能
- **用户管理**：支持管理员、教师和学生三类角色，提供权限控制
- **通知系统**：发布和管理各类通知、公告
- **任务管理**：创建、分配和跟踪学生会任务
- **统计分析**：提供各类数据的统计和报表功能

### 技术特点
- **模块化架构**：核心功能和业务逻辑分离，便于维护和扩展
- **前端优化**：响应式设计，兼容多种设备
- **安全性保障**：密码加密存储、CSRF防护、输入验证等
- **本地数据持久化**：使用localStorage/sessionStorage存储数据

## 项目结构

```
├── css/                # 样式文件目录
├── images/             # 图片资源目录
├── js/                 # JavaScript文件目录（主入口）
├── modules/            # 模块化代码目录
│   ├── core/           # 核心功能模块
│   ├── features/       # 业务功能模块
│   └── utils/          # 工具函数模块
├── pages/              # HTML页面文件
├── README.md           # 项目说明文档
└── index.html          # 系统入口页面
```

## 安装与部署

1. **克隆或下载项目**
   将项目文件下载到本地服务器或直接在本地打开

2. **环境要求**
   - 现代Web浏览器（Chrome、Firefox、Safari、Edge等）
   - 本地存储权限（用于数据保存）

3. **启动方式**
   - 在浏览器中直接打开 `index.html` 文件
   - 或通过HTTP服务器（如Apache、Nginx）托管项目文件

## 使用指南

### 登录系统
- 系统预设了三个演示账号：
  - 管理员：用户名 `admin`，密码 `admin123`
  - 教师：用户名 `teacher`，密码 `teacher123`
  - 学生：用户名 `student`，密码 `student123`

### 主要功能使用

#### 管理员功能
- 用户管理：添加、编辑、删除用户账号
- 权限管理：设置用户角色和权限
- 系统设置：配置系统参数

#### 教师功能
- 查看学生信息
- 审批学生申请
- 发布通知和公告

#### 学生功能
- 查看个人信息
- 提交申请
- 查看通知和活动
- 完成分配的任务

## 技术栈

- **前端框架**：纯JavaScript实现，无第三方框架依赖
- **样式**：CSS3
- **数据存储**：localStorage/sessionStorage（本地存储）
- **安全**：自定义加密和安全验证机制

## 安全说明

### 数据安全
- 所有敏感数据在本地存储前均经过加密处理
- 密码使用加盐哈希存储，不可逆
- 实现了CSRF令牌防护和输入验证

### 使用建议
- 请勿在实际生产环境中直接使用本系统的默认安全配置
- 建议在真实环境中集成后端服务，而不是仅依赖本地存储
- 定期清理本地存储数据，避免数据过大影响性能

## 开发与扩展

### 模块开发
系统采用模块化设计，可以通过以下方式扩展功能：

1. **创建新模块**：在 `modules/features` 目录下创建新的功能模块
2. **注册模块**：在主入口文件中注册新模块
3. **实现接口**：遵循现有模块的接口规范实现功能

### 模块规范
- 每个模块应暴露标准接口（init, destroy, getInfo等）
- 使用 `moduleLoader` 进行模块管理
- 遵循项目的命名和代码规范

## 常见问题

### 登录问题
- 确保输入的用户名和密码正确
- 检查浏览器是否允许本地存储

### 数据问题
- 如果数据丢失，可能是浏览器清除了本地存储
- 定期导出重要数据进行备份

### 兼容性问题
- 确保使用现代浏览器的最新版本
- 如遇显示问题，尝试清除浏览器缓存
