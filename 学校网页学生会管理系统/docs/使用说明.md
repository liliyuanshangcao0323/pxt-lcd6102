# 学校网页学生会管理系统 - 使用说明

## 1. 系统概述

学校网页学生会管理系统是一个面向学校学生会管理的综合平台，提供学生管理、任务分配、通知发布、数据统计等功能。系统支持管理员、教师和学生三种角色，各角色拥有不同的权限和功能。

## 2. 系统要求

### 2.1 浏览器要求
- Google Chrome (推荐最新版)
- Mozilla Firefox (推荐最新版)
- Apple Safari (推荐最新版)
- Microsoft Edge (推荐最新版)

### 2.2 分辨率要求
- 最低分辨率: 1024x768
- 推荐分辨率: 1920x1080

### 2.3 其他要求
- JavaScript 必须启用
- 本地存储 (localStorage) 必须可用
- 网络连接 (用于未来扩展)

## 3. 登录系统

### 3.1 访问系统

1. 打开浏览器
2. 在地址栏输入系统网址或文件路径
3. 系统默认显示登录页面

### 3.2 登录流程

1. 在登录页面输入用户名和密码
2. 点击「登录」按钮
3. 系统验证成功后，自动跳转到对应角色的主页面

### 3.3 默认账号信息

| 用户名 | 密码 | 角色 |
|--------|------|------|
| admin  | admin123 | 管理员 |
| teacher | teacher123 | 教师 |
| student | student123 | 学生 |

> **注意**: 首次登录后，请立即修改密码确保安全

### 3.4 忘记密码

如果您忘记了密码，请联系系统管理员重置密码。

## 4. 管理员操作指南

### 4.1 仪表盘

管理员登录后，首先看到的是系统仪表盘，显示：
- 系统概览信息
- 用户统计数据
- 最新通知列表
- 待处理任务数量

### 4.2 用户管理

#### 4.2.1 查看用户列表

1. 点击左侧导航栏中的「用户管理」
2. 系统显示所有用户的列表，包含用户名、角色、注册时间等信息
3. 可以使用搜索框查找特定用户
4. 可以按列标题排序

#### 4.2.2 添加新用户

1. 在用户列表页面点击「添加用户」按钮
2. 在弹出的表单中填写用户信息：
   - 用户名（必填）
   - 密码（必填）
   - 确认密码（必填）
   - 用户角色（管理员/教师/学生）
   - 姓名、邮箱、电话等其他信息
3. 点击「保存」按钮
4. 系统提示添加成功

#### 4.2.3 编辑用户

1. 在用户列表中找到需要编辑的用户
2. 点击该用户对应的「编辑」按钮
3. 修改用户信息
4. 点击「保存」按钮

#### 4.2.4 删除用户

1. 在用户列表中找到需要删除的用户
2. 点击该用户对应的「删除」按钮
3. 在确认对话框中点击「确定」
4. 系统提示删除成功

> **注意**: 删除用户是不可逆操作，请谨慎操作

### 4.3 权限管理

#### 4.3.1 分配用户角色

1. 在用户列表页面找到目标用户
2. 点击「编辑」按钮
3. 在角色下拉菜单中选择新的角色
4. 点击「保存」按钮

#### 4.3.2 设置权限

1. 点击左侧导航栏中的「权限管理」
2. 选择用户或角色
3. 勾选或取消勾选相应的权限
4. 点击「保存设置」按钮

### 4.4 系统设置

1. 点击左侧导航栏中的「系统设置」
2. 可以设置以下内容：
   - 系统名称
   - 登录页标题
   - 系统公告
   - 密码策略
   - 会话超时时间
3. 修改完成后点击「保存」按钮

### 4.5 数据管理

#### 4.5.1 数据备份

1. 点击左侧导航栏中的「数据管理」
2. 选择「备份数据」
3. 点击「开始备份」按钮
4. 系统会生成备份文件并提供下载

#### 4.5.2 数据恢复

1. 点击左侧导航栏中的「数据管理」
2. 选择「恢复数据」
3. 点击「选择文件」按钮，选择备份文件
4. 点击「开始恢复」按钮

> **注意**: 数据恢复会覆盖当前数据，请谨慎操作

## 5. 教师操作指南

### 5.1 仪表盘

教师登录后，首先看到的是教师仪表盘，显示：
- 个人信息
- 待审批申请数量
- 任务完成情况统计
- 最新通知

### 5.2 学生管理

#### 5.2.1 查看学生列表

1. 点击左侧导航栏中的「学生管理」
2. 系统显示所有学生的列表
3. 可以使用搜索框查找特定学生

#### 5.2.2 查看学生详情

1. 在学生列表中找到目标学生
2. 点击学生姓名或「详情」按钮
3. 查看学生的详细信息，包括个人信息、任务完成情况等

### 5.3 任务管理

#### 5.3.1 创建任务

1. 点击左侧导航栏中的「任务管理」
2. 选择「创建任务」
3. 填写任务信息：
   - 任务名称
   - 任务描述
   - 截止日期
   - 优先级
   - 所属分类
4. 点击「保存」按钮

#### 5.3.2 分配任务

1. 创建任务后，可以在任务列表中选择该任务
2. 点击「分配」按钮
3. 选择要分配的学生
4. 点击「确认」按钮

#### 5.3.3 批改任务

1. 在任务管理页面，点击「已提交任务」
2. 选择需要批改的任务提交
3. 点击「批改」按钮
4. 输入分数和评语
5. 点击「提交评分」按钮

### 5.4 申请审批

1. 点击左侧导航栏中的「申请审批」
2. 系统显示待审批的申请列表
3. 点击申请标题查看详情
4. 根据情况点击「批准」或「拒绝」按钮
5. 填写审批意见
6. 点击「确认」按钮

### 5.5 通知管理

#### 5.5.1 发布通知

1. 点击左侧导航栏中的「通知管理」
2. 选择「发布通知」
3. 填写通知内容：
   - 标题
   - 内容
   - 接收对象（全体/特定班级/特定学生）
   - 重要程度
   - 发布时间
4. 点击「发布」按钮

#### 5.5.2 查看通知列表

1. 点击左侧导航栏中的「通知管理」
2. 选择「我的通知」
3. 查看所有已发布的通知

## 6. 学生操作指南

### 6.1 仪表盘

学生登录后，首先看到的是学生仪表盘，显示：
- 个人信息
- 待完成任务数量
- 已完成任务情况
- 最新通知

### 6.2 个人信息管理

1. 点击左侧导航栏中的「个人信息」
2. 查看个人基本信息
3. 点击「编辑」按钮修改信息
4. 修改完成后点击「保存」按钮

### 6.3 任务管理

#### 6.3.1 查看任务列表

1. 点击左侧导航栏中的「任务管理」
2. 系统显示所有已分配的任务
3. 任务分为「待完成」、「已提交」、「已批改」等状态

#### 6.3.2 查看任务详情

1. 在任务列表中点击任务名称
2. 查看任务的详细要求、截止日期等信息

#### 6.3.3 提交任务

1. 在待完成任务列表中选择任务
2. 点击「提交」按钮
3. 根据要求完成任务内容
4. 点击「确认提交」按钮

#### 6.3.4 查看任务评分

1. 在已批改任务列表中选择任务
2. 查看教师的评分和评语

### 6.4 通知查看

1. 点击左侧导航栏中的「通知中心」
2. 查看所有通知，未读通知会有特殊标记
3. 点击通知标题查看详情
4. 点击「标记为已读」按钮

### 6.5 申请提交

#### 6.5.1 提交申请

1. 点击左侧导航栏中的「申请中心」
2. 选择「提交新申请」
3. 选择申请类型
4. 填写申请内容
5. 点击「提交」按钮

#### 6.5.2 查看申请状态

1. 点击左侧导航栏中的「申请中心」
2. 选择「我的申请」
3. 查看所有申请的状态（待审批、已批准、已拒绝）
4. 点击申请标题查看详情和审批意见

## 7. 通用功能

### 7.1 修改密码

1. 点击右上角用户头像
2. 选择「修改密码」
3. 输入旧密码、新密码和确认新密码
4. 点击「保存」按钮

### 7.2 注销登录

1. 点击右上角用户头像
2. 选择「注销登录」
3. 系统退出当前账户并返回登录页面

### 7.3 搜索功能

在各个模块的列表页面，都有搜索框可以使用：
1. 点击搜索框
2. 输入关键词
3. 按回车键或点击搜索按钮
4. 系统显示搜索结果

### 7.4 筛选和排序

在列表页面，可以使用筛选和排序功能：
1. 点击筛选按钮选择筛选条件
2. 点击列标题可以按该列排序（升序/降序）

## 8. 常见问题解答

### 8.1 无法登录系统

- 检查用户名和密码是否正确
- 确保JavaScript已启用
- 清理浏览器缓存后重试
- 联系系统管理员重置密码

### 8.2 页面显示异常

- 刷新页面重试
- 检查浏览器版本是否兼容
- 清理浏览器缓存
- 调整屏幕分辨率

### 8.3 数据保存失败

- 检查网络连接
- 确保必填项已填写
- 检查输入格式是否正确
- 刷新页面后重试

### 8.4 忘记密码

- 联系系统管理员重置密码
- 管理员可以在用户管理模块重置用户密码

### 8.5 权限不足

- 确认当前用户角色是否有权限执行该操作
- 如需要提升权限，请联系系统管理员

## 9. 故障排除

### 9.1 浏览器兼容性问题

- 使用推荐的浏览器（Chrome、Firefox、Safari、Edge）
- 确保浏览器为最新版本
- 禁用可能导致冲突的浏览器插件

### 9.2 数据丢失或损坏

- 如遇数据问题，请立即联系系统管理员
- 系统管理员可以从备份恢复数据
- 定期备份重要数据

### 9.3 性能问题

- 关闭不必要的浏览器标签页
- 清理浏览器缓存和Cookie
- 检查系统资源使用情况
