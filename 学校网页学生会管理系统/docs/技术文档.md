# 学校网页学生会管理系统 - 技术文档

## 1. 系统架构

### 1.1 整体架构

学生会管理系统采用前端单页应用（SPA）架构，使用纯JavaScript实现，不依赖第三方框架。系统分为以下几个主要层次：

- **UI层**：HTML页面和CSS样式，负责用户界面展示
- **业务逻辑层**：模块化的JavaScript代码，实现各种业务功能
- **数据层**：使用浏览器本地存储（localStorage/sessionStorage）保存数据
- **安全层**：提供身份验证、授权和数据加密等安全功能

## 2. 核心模块说明

### 2.1 模块加载器 (moduleLoader)

模块加载器负责管理所有功能模块的注册、初始化和销毁，是系统的核心组件之一。

#### 主要功能
- 模块注册与管理
- 模块依赖解析
- 按顺序初始化模块
- 模块错误处理和重试机制
- 提供模块通信接口

#### API接口

```javascript
// 注册模块
moduleLoader.registerModule(moduleName, module, dependencies);

// 初始化所有模块
moduleLoader.initAllModules();

// 获取已注册的模块
moduleLoader.getModule(moduleName);

// 检查模块是否已初始化
moduleLoader.isModuleInitialized(moduleName);

// 获取模块加载状态
moduleLoader.getLoadingStatus();
```

### 2.2 认证模块 (auth)

认证模块处理用户登录、注销、会话管理和权限控制。

#### 主要功能
- 用户登录验证
- 会话状态管理
- 权限检查
- 用户角色控制
- 自动登录功能

#### API接口

```javascript
// 用户登录
auth.login(username, password);

// 用户注销
auth.logout();

// 检查是否已登录
auth.isLoggedIn();

// 获取当前用户信息
auth.getCurrentUser();

// 检查用户权限
auth.hasPermission(permission);

// 检查用户角色
auth.hasRole(role);

// 获取用户权限等级
auth.getUserLevel();
```

### 2.3 应用数据模块 (appData)

应用数据模块负责管理系统中的所有数据，包括用户数据、任务数据和通知数据。

#### 主要功能
- 数据加载和保存
- 数据查询和过滤
- 数据更新和删除
- 数据验证和清理
- 数据统计和分析

#### API接口

```javascript
// 初始化数据
appData.init();

// 保存数据到本地存储
appData.saveData();

// 加载数据
appData.loadData();

// 用户数据管理
appData.addUser(user);
appData.updateUser(username, userData);
appData.deleteUser(username);
appData.getUserByUsername(username);
appData.getAllUsers();

// 任务数据管理
appData.addTask(task);
appData.updateTask(taskId, taskData);
appData.deleteTask(taskId);
appData.getTaskById(taskId);
appData.getTasksByUser(username);

// 通知数据管理
appData.addNotification(notification);
appData.updateNotification(notificationId, notificationData);
appData.deleteNotification(notificationId);
appData.getNotificationById(notificationId);
appData.getNotificationsForUser(username);

// 数据统计
appData.getStatistics();
```

### 2.4 安全模块 (securityModule)

安全模块提供各种安全相关功能，包括密码加密、数据验证和防护机制。

#### 主要功能
- 密码加密和验证
- 数据验证和清理
- XSS和SQL注入防护
- CSRF保护
- 安全存储管理

#### API接口

```javascript
// 密码相关
securityModule.hashPassword(password, salt);
securityModule.verifyPassword(password, storedHash, salt);
securityModule.generateSalt();

// 输入验证
securityModule.validateUsername(username);
securityModule.validatePasswordStrength(password);
securityModule.validateEmail(email);
securityModule.validatePhone(phone);

// 数据安全处理
securityModule.sanitizeInput(input);
securityModule.encryptData(data);
securityModule.decryptData(encryptedData);
securityModule.preventSQLInjection(input);
securityModule.detectXSSAttack(input);

// 安全存储
securityModule.setSecureStorage(key, data, options);
securityModule.getSecureStorage(key, options);
securityModule.removeSecureStorage(key, options);

// CSRF保护
securityModule.generateCSRFToken();
securityModule.validateCSRFToken(token);
securityModule.addCSRFTokenToForms();

// 初始化安全模块
securityModule.init();
```

## 5. 系统流程

### 5.1 登录流程

1. 用户访问系统登录页面
2. 输入用户名和密码，点击登录
3. 系统验证用户凭据
4. 验证成功，记录用户会话，跳转至相应的仪表盘页面
5. 验证失败，显示错误信息

### 5.2 模块加载流程

1. 页面加载完成后，系统初始化主应用程序
2. 主应用程序加载核心模块（moduleLoader, auth, appData）
3. 根据用户权限，加载相应的功能模块
4. 各模块初始化，完成数据加载和UI渲染
5. 系统准备就绪，用户可以开始使用

### 5.3 数据处理流程

1. 用户通过UI操作触发数据变更
2. 业务模块处理用户请求，进行验证和处理
3. 数据更新通过appData模块保存到本地存储
4. UI根据新数据进行更新，反馈给用户

## 8. 开发指南

### 8.1 添加新模块

1. 在 `modules/features` 目录下创建新的模块文件
2. 实现模块接口（init, destroy等）
3. 在主入口文件中注册新模块
4. 添加必要的依赖声明
5. 实现相应的UI组件和业务逻辑

### 8.2 模块开发规范

- 遵循单一职责原则
- 提供清晰的API接口
- 实现错误处理和日志记录
