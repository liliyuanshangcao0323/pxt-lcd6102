学生会管理系统 - 模块加载示例

本页面展示了系统如何正确加载所有JavaScript模块，确保依赖关系和加载顺序

模块加载状态

HTML模块引入示例

<script src="../js/auth.js" defer></script> <script src="../js/appData.js" defer></script> <script src="../js/securityModule.js" defer></script> <script src="../js/moduleLoader.js" defer></script> <script src="../js/notificationModule.js" defer></script> <script src="../js/teacherModule.js" defer></script> <script src="../js/studentModule.js" defer></script> <script src="../js/adminModule.js" defer></script> <script defer> // 使用模块加载器等待所有模块加载完成 window.moduleLoader.onReady(function() { console.log('所有核心模块已加载，应用开始初始化'); // 在这里执行应用初始化逻辑 initApp(); }); function initApp() { // 应用初始化代码 console.log('应用初始化完成'); // 隐藏加载指示器 document.querySelector('.module-loading-indicator').classList.add('hidden'); } </script>

模块依赖关系

// 模块加载器中定义的依赖关系 dependencies: { auth: [], // 无依赖，可以首先加载 appData: ['auth'], // 依赖auth模块 securityModule: [], // 无直接依赖 notificationModule: ['auth', 'appData'], // 依赖auth和appData teacherModule: ['auth', 'appData', 'securityModule'], studentModule: ['auth', 'appData', 'securityModule'], adminModule: ['auth', 'appData', 'securityModule'] }
